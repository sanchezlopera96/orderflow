# 1. Registrar las decisiones de arquitectura

- Estado: aceptada
- Fecha: 2026-07-29

## Contexto

Este proyecto es un ejercicio técnico que se evalúa explícitamente por la arquitectura y por cómo
se comunican las decisiones. Las elecciones deben ser trazables y defendibles.

## Decisión

Mantenemos Architecture Decision Records (ADR) cortos en `docs/adr`, un archivo por decisión, con
un formato liviano (contexto, decisión, consecuencias).

## Consecuencias

- Cada trade-off relevante tiene un único lugar referenciable.
- El README enlaza a los ADR en vez de duplicar el razonamiento.
